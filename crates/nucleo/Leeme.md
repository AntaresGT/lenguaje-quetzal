# nucleo

Tipos base compartidos por todo el Lenguaje Quetzal: representación del código fuente (`Fuente`), ubicaciones y spans (`Ubicacion`, `Posicion`), el error central del lenguaje (`ErrorQuetzal`) con su categoría y código, y el alias `ResultadoQuetzal`.

Este crate no depende de ningún otro crate del workspace; todos los demás dependen de él.
