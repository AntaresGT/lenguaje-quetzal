# repl

REPL interactivo del Lenguaje Quetzal (`qz>`). Usa el mismo `motor` que la ejecución normal pero conserva el estado entre líneas: variables, funciones y módulos importados. Soporta historial, entrada multilínea cuando un bloque no está cerrado y comandos internos (`salir`, `:ayuda`, `:limpiar`, `:cargar`, `:modulos`, `:estado`).
