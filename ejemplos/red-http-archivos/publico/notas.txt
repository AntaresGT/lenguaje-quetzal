Se sirve de dos formas distintas en este ejemplo:

1. Automáticamente, bajo /publico/notas.txt, gracias a
   servidor.estaticos("/publico", "publico").
2. Explícitamente, bajo /notas, mediante una ruta que llama a
   Respuestas.archivo("publico/notas.txt") a mano.

Pruébalo con Range para ver una respuesta 206 Partial Content:
  curl -r 0-19 http://127.0.0.1:8080/publico/notas.txt

Y con un If-None-Match repetido para ver un 304 Not Modified:
  curl -i http://127.0.0.1:8080/publico/notas.txt
  curl -i -H "If-None-Match: <etag-de-la-respuesta-anterior>" \
       http://127.0.0.1:8080/publico/notas.txt
